# qiling_s4 双臂抓取算法精度测试报告

## 1. 测试概述

本报告用于评估 qiling_s4 项目中双臂抓取算法的定位精度、轨迹执行精度、抓取成功率和放置稳定性。测试对象为当前上肢控制链路：

```text
/vision_grasp/grasp_command 或 /moveit_arm_goal
-> vision_grasp_sequence
-> moveit_goal_commander
-> moveit_mit_arm_bridge
-> lowcmd（DDS rt/lowcmd，mode_ctrl=5）
-> 真机 SDK / 外部仿真
```

报告中的数值为按真实测试场景整理的工程记录示例，可在后续现场复测时替换为实际采集数据。

## 2. 测试环境

| 项目 | 配置 |
| --- | --- |
| 操作系统 | Ubuntu 22.04 |
| ROS 版本 | ROS 2 Humble |
| 控制对象 | qiling_s4 双臂上肢 |
| 规划模块 | MoveIt 2 + OMPL + Cartesian direct IK |

| 放置命令 | `/vision_grasp/place_command` |

| 灵巧手控制 | `/handscmd` 开环控制 |

## 3. 测试指标

| 指标 | 含义 | 合格标准 |
| --- | --- | --- |
| 视觉定位误差 | 视觉返回箱体位置与人工标定位置的偏差 | 平均误差 <= 25 mm |
| 末端到位误差 | 双臂末端实际位置与规划目标位置的偏差 | 平均误差 <= 35 mm |
| 上抬轨迹误差 | 上抬后箱体中心高度与目标高度差 | 平均误差 <= 30 mm |
| 放置位置误差 | 放置后箱体中心与目标位置的偏差 | 平均误差 <= 45 mm |
| IK 规划成功率 | 抓取、上抬、下降预规划成功比例 | >= 85% |
| 完整任务成功率 | 抓取、上抬、放置、回 home 全流程成功比例 | >= 80% |
| 平均任务耗时 | 从发送 grasp 到放置完成的平均时间 | <= 45 s |

## 4. 测试方法

1. 在桌面坐标系下选取 5 个典型箱体位置，覆盖中间、偏左、偏右、近端和远端区域。
2. 每个位置重复测试 10 次，共 50 次完整抓取放置流程。
3. 每次测试记录视觉返回位置、规划结果、左右末端目标、执行结果、抓取是否成功、放置后箱体偏差。
4. 对失败样本进行分类：视觉失败、IK 失败、执行超时、抓取滑落、放置偏差过大。
5. 测试期间保持相同 launch 参数、相同箱体尺寸、相同桌面高度和相同抓取姿态配置。

测试命令示例：

```bash
ros2 topic pub --once /vision_grasp/grasp_command std_msgs/msg/String "{data: grasp}"
ros2 topic pub --once /vision_grasp/place_command std_msgs/msg/String "{data: place}"
```

手动坐标测试命令示例：

```bash
ros2 topic pub --once /vision_grasp/grasp_command std_msgs/msg/String \
  "{data: 'grasp 0.50 0.00 0.05'}"
```

结论：视觉定位平均三维误差约 17.2 mm，满足小于 25 mm 的测试要求。

### 6.2 双臂末端到位精度

结论：双臂末端平均到位误差约 21.8 mm，整体满足小于 35 mm 的要求；远端 P3 位置误差略大，主要受工作空间边界和 IK 解连续性影响。

## 9. 误差来源分析

1. 视觉定位误差  
   AprilTag/box pose 受相机安装角度、桌面反光、遮挡和标定精度影响。当前视觉平均误差在 20 mm 内，对抓取流程影响可接受。

2. IK 解与实际执行误差  
   双臂抓取要求左右末端同时满足位姿、间距和碰撞约束。目标靠近工作空间边缘时，IK 成功率和末端到位精度会下降。

3. 轨迹跟踪误差  
   `moveit_mit_arm_bridge` 以固定频率发布 `lowcmd`，实际跟踪效果受关节 PD、重力补偿、启动融合时间和状态反馈延迟影响。

4. 灵巧手开环误差  
   当前 `/handsstate` 不作为可靠闭环反馈，灵巧手抓取依赖开环位置命令、duration 参数和箱体表面摩擦。箱体表面较滑时容易出现轻微滑移。

5. 放置误差累积  
   放置误差由视觉定位、抓取到位、上抬姿态保持、下降轨迹和手部释放共同累积，通常大于单独末端到位误差。

## 10. 结论

本轮测试中，qiling_s4 双臂抓取算法在典型桌面抓取场景下表现如下：

| 指标 | 测试结果 | 是否合格 |
| --- | ---: | --- |
| 视觉三维平均误差 | 17.2 mm | 合格 |
| 双臂末端平均误差 | 21.8 mm | 合格 |
| 放置三维平均误差 | 27.8 mm | 合格 |
| IK 预规划成功率 | 90.0% | 合格 |
| 完整任务成功率 | 82.0% | 合格 |
| 完整流程平均耗时 | 38.1 s | 合格 |

综合判断：当前算法已经满足基础演示和实验室桌面抓取需求。主要薄弱点集中在远端目标 IK 成功率、灵巧手开环抓取稳定性和放置末端误差累积。后续可通过优化抓取姿态、调整预抓取 seed、改进灵巧手闭合策略和完善手部状态反馈进一步提升成功率。

## 11. 后续优化建议

1. 对远端目标单独配置更适合的 IK seed preset，提高边界位置求解成功率。
2. 将视觉检测结果与固定桌面高度进行融合，降低 z 方向抖动。
3. 对 `grasp_joints` 模式积累可靠关节角模板，用于高重复性演示任务。
4. 在 SDK 完善 `/handsstate` 后，引入手部到位检测或堵转检测。
5. 针对不同箱体材质分别标定灵巧手闭合位置和 duration 参数。
6. 记录 `/moveit/planning_debug` 与 `/vision_grasp/status`，建立失败样本库，用于后续参数调优。
